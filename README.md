# Mamut Tours

Landing page for **Mamut Tours**, a private tour service in Medellín, Colombia. It presents destinations, services and a direct WhatsApp booking channel.

## Features

- **Destinations section**: Comuna 13, Guatapé & El Peñón, Pueblito Paisa, Parque Arví, Jardín and Santa Fe de Antioquia.
- **Services section**: private van, local guide, flexible schedules, hotel pickup, family/group tours and custom itineraries.
- **Contact via WhatsApp**: click-to-chat links with a pre-filled message.
- **Responsive layout**: mobile navigation menu and media queries for small screens.
- **Custom typography** with Google Fonts (Fraunces + Manrope).

## Tech stack

- HTML5
- CSS3 (Flexbox/Grid, media queries)
- Vanilla JavaScript (mobile menu)

## Run locally

No build step needed. Clone the repo and open `index.html` in a browser:

```bash
git clone https://github.com/F4ls0/Mamut-Tours.git
cd Mamut-Tours
# open index.html
```
